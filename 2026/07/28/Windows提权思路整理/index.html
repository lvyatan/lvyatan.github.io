Windows 提权思路整理

发表于 2026-07-28 更新于 2026-09-01 分类于 后渗透 本文字数： 911 阅读时长 ≈ 3 分钟

0x00 前言

拿到 Windows 普通权限 shell 后，提权是后渗透关键。本文梳理 Windows 提权的常见路径与命令速查。仅用于授权环境。

0x01 基本信息收集

重点：

  • systeminfo 看 OS 版本、补丁数、域 / 工作组
  • wmic qfe 看缺哪些补丁 → 对照 CVE
  • whoami /priv 看当前用户特权

0x02 内核漏洞提权

利用流程：

  1. 拿 OS 版本与补丁列表
  2. 上 Watson 或 Windows-Exploit-Suggester（基于 systeminfo 输出）
  3. 对应 CVE 找现成 EXP

经典 CVE：

  • MS16-032（CVE-2016-0099）：Win7/2008 R2，提权到 SYSTEM
  • MS16-135（CVE-2016-7255）：Win10 早期版本
  • CVE-2021-1675 / PrintNightmare：Print Spooler 漏洞，可加管理员
  • CVE-2022-26809：RPC 漏洞

EXP 仓库：Windows-Kernel-Exploits

0x04 DLL 劫持

服务/进程加载 DLL 顺序：

  1. 应用所在目录
  2. System32
  3. System
  4. Windows
  5. 当前工作目录
  6. PATH 变量

如果应用目录可写，往里塞恶意 DLL 同名文件，启动时被加载。

工具：

  • SioBaDoU工具
  • Process Monitor 监控 Name not found 找缺失的 DLL

0x09 防御建议

  • 及时打补丁，订阅 MSRC 公告
  • 最小权限原则：服务账户用 gMSA，不用 SYSTEM
  • 启用 LSA Protection（RunAsPPL）
  • 受限服务权限（sc sdshow 看 SDDL）
  • Application Control + WDAC 拦截未授权 PE
  • 监控 Mimikatz 之类工具的进程创建
  • Defender ATP 开 LSA 凭据保护

0x10 总结

Windows 提权思路：配置错误 > 内核漏洞 > 凭据泄露。一份 WinPEAS + systeminfo 走天下，但理解原理才能在没工具时手动挖洞。
