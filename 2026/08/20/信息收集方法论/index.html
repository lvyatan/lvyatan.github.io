渗透测试信息收集方法论

发表于 2026-08-20 更新于 2026-09-01 分类于 渗透测试 本文字数： 549 阅读时长 ≈ 2 分钟

“渗透的本质是信息收集。” ——TK 教主

信息收集占整个渗透测试 60-70% 的时间，质量直接决定后续打点的效率。本文梳理一份完整的方法论与工具清单。

一、企业资产测绘

1.1 工商信息

  • 企查查、天眼查、爱企查：拿全母公司、子公司、控股关系
  • 国家企业信用信息公示系统：最权威

1.2 ICP 备案

  • 工信部 ICP 备案查询：beian.miit.gov.cn
  • 站长之家、爱站：批量查同一备案号的资产

1.4 IP 段 & C 段

  • Whois：whois 1.2.3.4 拿 AS 号与网段
  • Censys / Shodan / Fofa / ZoomEye：反向查找
  • 各厂 IDC：阿里云、腾讯云 IP 段白名单

二、Web 资产发现

2.1 端口扫描

2.2 Web 指纹

  • Wappalyzer 浏览器插件：一键看技术栈
  • httpx：批量 HTTP 探活 + 标题 + 状态码 + 指纹
  • fingerprinthub / EHole：国内指纹库
  • Gobuster / ffuf：目录爆破

2.3 搜索引擎语法

引擎 语法示例
Google site:target.com intitle:"管理后台"
Fofa domain="target.com"
Shodan hostname:target.com port:"3389"
ZoomEye site:target.com
Censys services.port=443 AND services.tls.certificates.leaf_data.subject.common_name="target.com"
Quake domain:"target.com"

三、Github & 代码泄露

四、人员与社工

  • LinkedIn / 脉脉：找员工
  • Github：员工 ID、提交邮箱
  • 邮箱格式推断：firstname.lastname@target.com

五、SaaS / 云资产

  • 子域 CNAME 指向云：[Takeover 漏洞] 重点
  • S3 Bucket 翻找：s3://target-backups/

六、信息整理

最终产出三张表：

  1. 资产表：IP/域名/端口/服务/版本/标题
  2. 漏洞清单：CVE 编号 + 状态 + 优先级
  3. 攻击路径图：内网横向起点 → 终点

一份整理良好的信息收集文档，就是渗透报告的 80%。

七、合规与法律边界

仅对授权目标进行测试。任何未授权的扫描 / 探测均属于违法行为，请勿越界。
