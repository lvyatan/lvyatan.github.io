0x00 前言

Nmap 是渗透测试中绕不开的神级扫描工具。本文梳理常用参数、扫描类型与绕过技巧，作为命令速查表使用。

0x02 主机发现

判断主机在线（不在线的不会做端口扫描）：

参数 含义
-sn 只做主机发现，不扫端口
-Pn 跳过主机发现，强制扫描
-PS80,443 TCP SYN Ping 指定端口
-PA80 TCP ACK Ping
-PE ICMP Echo Ping（容易被墙）
-PU UDP Ping
-n 不做 DNS 解析（加速）

内网做信息收集，-sn 摸清存活主机非常关键：
nmap -sn 192.168.1.0/24 -oG alive.txt

0x03 端口扫描类型

参数 类型 备注
-sS SYN 半开扫描 默认且最快，需 root
-sT TCP 全连接 不需 root，但日志多
-sU UDP 扫描 慢，常用 --top-ports 100
-sA ACK 扫描 测防火墙规则
-sF / -sX / -sN FIN/Xmas/Null 绕过部分无状态防火墙

0x04 常用实战组合

1. 快速扫常见端口

2. 全端口 + 服务识别

  • -p- 全 65535 端口
  • -sV 服务版本
  • -A 综合探测（OS、脚本、Trace）
  • -T4 加速时序

3. 脚本引擎 NSE

4. 输出报告

  • -oN 人类可读
  • -oX XML（导入其他工具）
  • -oG grep 友好
  • -oA all 三种格式同时输出

0x06 性能与加速技巧

  • -T0~5：时序模板，0 最慢最隐蔽，5 最快最吵闹
  • --min-rate 1000：最低发包速率
  • --max-retries 2：重试上限
  • --host-timeout 30m：单主机超时
  • -n：不做 DNS 反查，加速 5-10 倍

0x07 学习建议

  • 官方文档 nmap.org/book 是唯一权威
  • 搭建本地靶场：Metasploitable2、Vulnhub
  • 多看 NSE 脚本，自己改一份
