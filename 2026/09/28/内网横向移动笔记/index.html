0x07 隐蔽通信

  • DNS 隧道：dnscat2 / CS DNS Beacon

  • SMB Beacon：内网命名管道，跨跳板
  • 代理链：proxychains + ssh / CS pivot listener

0x08 持久化

  • DLL 劫持：常用软件启动加载
  • WMI Event Subscription：永久订阅
  • Services：自启服务
  • Scheduled Tasks：定时唤起
  • Golden Ticket：10 年有效
  • Skeleton Key：万能密码（域控上 mimikatz misc::skeleton）
  • AdminSDHolder：受保护对象属性修改

0x09 防御侧

  • 分层隔离（边界 / 内网 / 核心数据）
  • 域管最小化，分账号
  • 启用 LSASS 保护（RunAsPPL）
  • 启用 LSA Cred Guard
  • 关 SMBv1、强制 SMB 签名
  • 监控 4624 / 4672 / 4768 等事件
  • EDR 监控 mimikatz、lsass dump、异常 Kerberos 票据
  • 红队演练常态化

0x10 总结

内网渗透本质是”凭据流转 + 域控接管”。所有横向移动技术都是为了在凭据体系里找到下一步。Mimikatz + Impacket + Cobalt Strike 是黄金三件套，PowerView / certipy / ADReon 是信息收集最佳实践。
