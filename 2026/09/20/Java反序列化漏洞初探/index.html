发表于 2026-09-20 更新于 2026-09-01 分类于 Web 渗透 本文字数： 971 阅读时长 ≈ 4 分钟

0x00 前言

Java 反序列化漏洞从 Apache Commons Collections 系列爆出后，几乎每年都有大瓜。Fastjson、Shiro、Log4j2 都被它折磨过。本文梳理原理、利用面与防御。仅用于合法授权环境。

0x01 原理

1. Java 序列化

字节流含：

  • 类的全限定名
  • 字段名 + 类型 + 值
  • 类的 serialVersionUID
  • 父类信息

0x03 实战利用

1. ysoserial 一键生成

2. 投递方式

把 payload 字节流塞进任何反序列化点：

  • HTTP Cookie：很多框架把 session 序列化
  • RMI/JMX：直接发到 1099 端口
  • JNDI 注入：LDAP / RMI 服务
  • HTTP 报文体：POST body
  • 自定义协议：比如 Java WebService 的 SOAP

0x05 JNDI 注入利用

JNDI 是反序列化漏洞最常见的”出口”。

绕过 JDK 高版本 trust 限制：

  • 本地 Gadget（Tomcat EL 表达式链）
  • RMI 序列化
  • LDAP Reference（高版本被禁用远程 classloader）

0x08 总结

反序列化漏洞本质是”反序列化过程会调用对象方法”这一设计。所有 Java 反序列化漏洞都能套用入口链 + 中间链 + 危险链的模板。掌握 ysoserial 一键生成 + JNDI 投递两条路，再去看各种新爆出的链会清晰很多。
