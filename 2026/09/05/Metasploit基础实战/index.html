0x00 前言

Metasploit Framework（MSF）是渗透测试事实标准。本文梳理核心命令、模块分类、payload 生成与实战流程。仅用于合法授权环境。

0x01 模块分类

模块 作用
Exploit 漏洞利用
Payload 漏洞利用成功后执行的代码
Auxiliary 辅助模块（扫描、嗅探、Fuzz、密码爆破）
Post 后渗透模块（提权、信息收集）
Encoder 编码器，绕过 AV/IDS
Nops 空指令，缓冲区对齐

0x09 后渗透常用模块

路径 用途
post/windows/gather/hashdump 抓 SAM 哈希
post/multi/manage/shell_to_meterpreter 普通 shell 升级 Meterpreter
post/multi/recon/local_exp_suggester 自动枚举提权建议
post/windows/gather/credentials/credential_collector 收集凭据
post/multi/manage/migrate 迁移进程到稳定进程
post/windows/manage/persistence 持久化

0x10 免杀技巧

  • shikata_ga_nai + 多次迭代：经典编码器，可绕过部分 AV
  • 自定义 payload：基于 stageless + 加密 stub
  • Veil Framework：生成免杀 payload
  • C# 模板 + AES 解密：Meterpreter stage 加密嵌入
  • 流程注入：编译 native exe，运行时注入 shellcode

0x11 防御与检测

  • EDR 监控 msfvenom 生成 exe 的特征
  • 网络层 IDS 规则匹配 Meterpreter 通信
  • 限制出网：内部服务器只能经代理出网
  • 进程白名单（WDAC）
  • 启用 Defender 实时保护 + AMSI

0x12 总结

MSF 是渗透的瑞士军刀。会用 search + info + show options 三板斧，再背几个常驻 payload，就能搞定 80% 的自动化利用工作。
