0x05 解题流程建议

  1. F12 看源码：注释、隐藏字段、JS
  2. 看 robots.txt / .git / .svn / .DS_Store
  3. dirsearch 扫后台
  4. 测试 SQL / SSTI / 文件读取 / XSS
  5. 抓包看接口：Repeater 调试参数
  6. 回显差时用 OOB：burp collaborator
  7. 看 cookie / token：JWT 解码看 alg
  8. 从题目名 / 描述 / 注释里找 hint

0x06 总结

CTF Web 的考点其实不多，三十道题覆盖 80% 知识点。把每个题的漏洞原因 + 利用链 + 修复方案都吃透，比刷 200 道流水题有效得多。
